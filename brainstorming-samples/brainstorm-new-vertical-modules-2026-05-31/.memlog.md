- (insight) Distribution clue: many top ideas spread underground (divorce, sobriety, immigration, pro-se) precisely because they are private or stigmatized, so privacy-first local AI is a feature not a bug for this catalog

- (insight) The Shadow Profession is reusable as a moat-detector lens over every idea: if a module cannot name the expensive expert it replaces, it is a prompt pack not a BMad module
- (insight) Sleeper pick: Dungeon Master's Forge is the most visibly magical demo of multi-agent structure to a newcomer and spreads via evangelist hobbyist communities; possibly the best first public demo
- (insight) Unifying spec for the non-SWE catalog: gatekept expensive expertise + charged life moment + a reason to keep it private; the triangle a generic prompt pack structurally cannot occupy
